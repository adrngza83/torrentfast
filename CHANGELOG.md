# Changelog

Formato basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/); versiones según [SemVer](https://semver.org/lang/es/).

## [1.0.0] - 2026-11-07
### Agregado
- Motor de descarga con libtorrent 2.x afinado para velocidad (hasta 2000 conexiones, DHT, LSD, UPnP/NAT-PMP, trackers extra, cifrado).
- Interfaz web con colores por estado, filtros, modo enfoque y acceso desde el celular.
- Soporte de magnets y archivos `.torrent`, descarga secuencial, pausar/reanudar y reanudación tras cerrar.
- Versión de terminal (`TorrentFast-CLI.exe`).
- Compilación automática de `.exe` para Windows con GitHub Actions.
